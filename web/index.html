Open message headers

Open a message you received. Paste its headers up to the first blank line, or choose its saved .eml file.

Where to find the headers
  • Gmail on a computer. Open the message. In the menu beside Reply, choose Show original. Copy the header block or download the original. Gmail instructions ↗
  • New Outlook or Outlook on the web. Open More actions, then View → View message details. In classic Outlook for Windows, open the message in its own window and select File → Properties → Internet headers. Outlook instructions ↗

You can paste only the Received and Authentication-Results fields, including their indented continuation lines. Add DKIM-Signature fields to inspect the signing domains and selectors. Message bodies and attachments are unnecessary.
